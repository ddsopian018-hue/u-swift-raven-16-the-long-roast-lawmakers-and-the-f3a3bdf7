One satirical sentence, 312 characters, roasting the lawmakers who write the rules for AI, crypto, and the internet — and cannot convert a file to PDF. It sets up the lawmaker's authority first (she chairs the committee that decides what your wallet may hold, what your AI may say, what the internet may show), then undercuts it with the file she cannot convert: her own 87-page draft, forwarded to a nineteen-year-old intern with one desperate line, converted in four seconds. The punch lands on the last words, and the detail is specific instead of a worn tech-illiteracy cliché. `main.py` (pure Python standard library, deterministic, no network) writes exactly that sentence to `entry.txt`.

## Run it

```sh
python3 main.py
```

The sentence is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is absent). The program refuses to emit anything outside 1–320 characters or containing a newline, and it only ever emits a single sentence.
